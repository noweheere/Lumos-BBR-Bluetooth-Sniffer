COMMUNICATION CONNECTIONS:
=========================

Wireless (ESP-NOW): No physical connections needed
- Both ESP32s use built-in WiFi for communication
- Range: ~50-100 meters in open space
- Automatic pairing via MAC addresses

Wired Backup (Serial):
Sniffer ESP32     Trailer ESP32
     TX ──────────── RX  
     RX ──────────── TX
    GND ──────────── GND

- Use appropriate fuses for each circuit

STATUS LED PATTERNS:
===================

Sniffer ESP32:
- Solid ON: Scanning active
- Quick flash: Device detected
- Slow blink: No devices found
- Fast blink: Error condition

Trailer ESP32:
- Solid ON: Connected and receiving commands
- Slow blink: Waiting for connection
- Fast blink: Error or emergency stop
- Off: No power or system fault

INSTALLATION NOTES:
==================

1. Mount ESP32s in weatherproof enclosures
2. Use automotive-grade wire (14 AWG minimum for power)
3. Install inline fuses for all high-current circuits
4. Secure all connections with heat shrink tubing
5. Test thoroughly before final installation
6. Keep antennas away from metal surfaces for best range

TESTING CONNECTIONS:
===================

Before applying power:
1. Check all connections with multimeter (continuity)
2. Verify no shorts between power and ground
3. Confirm correct polarity on all connections
4. Test each MOSFET gate voltage (should be 0V when off)

After applying power:
1. Verify 5V at ESP32 VIN pins
2. Check 12V at LED strip positive terminals
3. Test each output with multimeter before connecting LEDs
4. Monitor current draw during initial testing

TROUBLESHOOTING:
===============

No Power:
- Check fuses and main power connections
- Verify 12V-to-5V converter output
- Test with multimeter

LEDs Not Working:
- Check MOSFET gate voltages (3.3V when on, 0V when off)
- Verify LED strip polarity
- Test MOSFETs with simple LED and resistor

Communication Issues:
- Verify MAC addresses in code
- Check ESP32 power stability
- Test at shorter distances first
- Monitor serial output for error messages

For more detailed troubleshooting, see the Testing Guide.
