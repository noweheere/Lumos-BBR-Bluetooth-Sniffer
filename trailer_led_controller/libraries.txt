# Required Libraries for Trailer LED Controller
# Install these through Arduino IDE Library Manager

# LED Strip Control
FastLED@3.6.0

# Web Server Libraries
ESPAsyncWebServer@1.2.3
AsyncTCP@1.1.1

# JSON Handling
ArduinoJson@6.21.3

# Core ESP32 Libraries (included with ESP32 board package)
# - WiFi
# - FS
# - SPIFFS

# Installation Instructions:
# 1. Open Arduino IDE
# 2. Go to Tools -> Manage Libraries
# 3. Search for each library name
# 4. Install the specified version or latest stable version
# 5. Restart Arduino IDE

# Board Package Required:
# ESP32 by Espressif Systems (version 2.0.0 or later)
# Add board manager URL: https://dl.espressif.com/dl/package_esp32_index.json

# FastLED Configuration Notes:
# - Supports WS2812B, SK6812, APA102, and many other LED types
# - Hardware SPI available on ESP32 for better performance
# - See FastLED examples for advanced features
